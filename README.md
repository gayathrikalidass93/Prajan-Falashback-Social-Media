# Prajan's Time Travel

An educational storytelling project in which Prajan explores ancient Tamil history, engineering, science, culture, and everyday life through imaginative time-travel adventures.

> **Project vision:** Create a parent-managed content studio, a child-friendly learning website, and a responsible social-media presence—all powered by one organised episode library.

## The three parts

1. **Production studio (build first):** Track episode ideas, research, scripts, scene prompts, voiceovers, visuals, edits, approvals, and publishing status.
2. **Learning website (build second):** Publish episodes with age-appropriate explanations, vocabulary, quizzes, and activities.
3. **Social media workflow (build third):** Prepare platform-specific captions, thumbnails, short clips, schedules, and performance notes. Publishing should require a parent/admin review.

## Editorial and child-safety principles

- A parent/guardian manages accounts, comments, messages, uploads, and public interactions.
- Do not publish a child's school, home, routine, live location, contact details, or other identifying information.
- Use only photos, voice recordings, and likenesses for which the parent/guardian has appropriate permission.
- Avoid collecting personal information from child visitors. Any future interactive features should be designed with privacy and applicable child-safety laws in mind.
- Clearly distinguish documented history from imaginative dialogue or reconstructed scenes.
- Verify historical claims with reliable sources before publishing.

## Historical storytelling note

The first planned episode explores **Kallanai (Grand Anicut)** on the Kaveri. It is traditionally associated with Karikala Chola. Scripts should describe the structure as a water-diversion and irrigation work, and label imagined conversations or uncertain construction details as creative reconstruction.
